# 沉浸式天气预报

单文件自包含的沉浸式动态天气预报页面（HTML + CSS + 原生 JavaScript，零构建依赖，双击即可打开）。

## 功能

- 7 种天气动态场景：晴 / 多云 / 阴 / 小雨 / 雷雨 / 雪 / 雾，配色、太阳、云层视差、雨雪粒子、闪电、薄雾逐项定制
- 差异化环境声（点击右上角喇叭开启）：鸟语 / 风声 / 雨滴哒哒 / 雷雨轰鸣 / 雪落沙沙，阴天与雾天静音
- 真实数据：Open-Meteo（免费免注册），支持 6 城市切换、实况与场景预览双模式
- 未来 7 天预报（含温度区间条）+ 未来 24 小时气温曲线（ECharts）
- 数据获取失败时自动回退演示数据

## 使用

直接打开 `沉浸式天气预报.html` 即可。空气指数因 Open-Meteo 无此字段显示「暂无」，提供和风天气 Key 后可补齐。
